# grade-calculator

A simple console program in C++ for teachers that calculates each student's average score and letter grade from five scores, as well as the overall class average and number of students entered.

## Requirements

- The program shall repeatedly prompt for a student's name until the user enters `end` to finish.
- The program shall accept 5 integer scores (from 0 to 100) for each student.
- The program shall display an error message and re-prompt for a score if the entered value is outside the 0–100 range.
- The program shall calculate each student's average score and assign the corresponding letter grade (A, B, C, or F).
- The program shall display the total number of students entered and the class average when finishing.

## Grading scale

| Grade | Average |
|-------|---------|
| A | 90 - 100 |
| B | 75 - 89.99 |
| C | 60 - 74.99 |
| F | Below 60 |

## How to run

1. Open https://www.onlinegdb.com and choose C++.
2. Paste the code from main.cpp and click Run.
